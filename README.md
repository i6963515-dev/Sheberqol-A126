# SheberQol — HTML + CSS

SheberQol — қазақ қолөнершілерінің бұйымдарын көрсететін қарапайым адаптивті веб-сайт. Бұл нұсқа таза HTML, CSS және JavaScript-пен жасалған, React немесе Node.js қажет емес.

## Файлдар
- `index.html` — сайт құрылымы мен мазмұны
- `style.css` — дизайн және телефонға бейімделу
- `script.js` — санат бойынша сүзгілеу, іздеу, таңдаулылар, себетке қосу және контраст режимі

## Компьютерде ашу
`index.html` файлын браузерде ашыңыз. VS Code қолдансаңыз, Live Server кеңейтімімен ашуға болады.

## GitHub Pages арқылы жариялау
1. GitHub-та `SheberQol` атты репозиторий жасаңыз.
2. Осы үш файлды (`index.html`, `style.css`, `script.js`) репозиторийдің негізгі деңгейіне жүктеңіз.
3. Репозиторийден **Settings → Pages** бөліміне кіріңіз.
4. **Deploy from a branch** таңдап, `main` және `/(root)` таңдаңыз, сақтаңыз.
5. Біраз уақыттан соң Pages бөлімінде сайт сілтемесі шығады.

## Ескерту
Өнім фотолары Unsplash сайтынан интернет арқылы жүктеледі, сондықтан суреттерге интернет керек. Себет пен таңдаулылар — тек браузер ішіндегі демонстрациялық функциялар; нақты тапсырыс, төлем немесе деректер базасы жоқ.
